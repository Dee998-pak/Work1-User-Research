# Week 3 — UI Design Principles & Grid Systems

This repository package completes the Week 3 internship practical task:

1. Establish a design system with color codes and typography scales.
2. Define layout parameters using a 12-column desktop grid and 4-column mobile grid.
3. Provide high-fidelity responsive UI mockups.
4. Verify selected color combinations against WCAG contrast guidance.
5. Provide a PDF style guide for repository documentation.

## Files
- `README.md` — project overview and implementation notes.
- `docs/Week3_UI_Design_Solution.docx` — detailed submission report.
- `docs/Week3_Style_Guide.pdf` — PDF style guide.
- `src/index.html` — responsive high-fidelity mockup.
- `src/styles.css` — design tokens, grid system, components and responsive behavior.
- `src/app.js` — small interaction demo.
- `docs/design-system.md` — design-token reference.
- `docs/wcag-contrast.md` — contrast verification.
- `docs/grid-specification.md` — grid specifications.

## How to run
Open `src/index.html` in a browser, or from the repository root run:
```bash
python -m http.server 5500
```
Then open `http://localhost:5500/src/`.

## Figma mapping
Recreate the same tokens as Figma Variables/Styles, create 1440px desktop and 390px mobile frames, apply the specified grids, and build components using the supplied mockup as the visual reference.


## Visual assets

The `assets/` folder contains actual PNG files for the colorful color-token sheet, responsive grid reference, and high-fidelity mockup.
