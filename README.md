# Work1: User Research & Discovery

Welcome to the User Research repository. This project covers the initial discovery and research phases of the UI/UX design cycle, focusing on understanding user behaviors, goals, and frustrations.

## 📁 Repository Contents
* **01_User Interview Document.docx** – Insights and transcripts from target audience interviews.
* **02_Customer Persona.docx** – Ideal user profiles representing our core demographic.
* **03_Empathy Map.docx** – Detailed mapping of what users say, think, do, and feel.
* **04_Pain Points.docx** – Summary of primary user frustrations and system bottlenecks.
* **05_Research Summary.docx** – Key findings and data synthesis guiding the design strategy.
